# MediFlow クリック可能プロトタイプ（GitHub Pages用）

Figmaファイル（fileKey: T96h4UyuX72YjeNLHJ1s3Z、Haruki Hoshiチーム）の
全69画面をHTML化し、ボタンリンクで画面遷移できるようにしたプロトタイプ。
バックエンドはなく、ログイン認証やデータ保存は動作しない（デモ用）。

## 構成
- `index.html` — 入口。利用者／病院側／管理者を選び、全画面一覧へ
- `user/` — 利用者 33画面（01.html 〜 33.html）
- `hospital/` — 病院側 23画面（01.html 〜 23.html）
- `admin/` — 管理者 13画面（01.html 〜 13.html）
- `assets/style.css` — 全画面共通の見た目（色・フォントはFigmaから抽出）

## 画面遷移の付け方
- 各画面の主要ボタンは、画面名から自然につながる次画面へリンクする
  （例：利用者01ログインの「ログイン」→ 02ログイン完了）
- ヘッダーの「‹」は前の画面／マイページ等、文脈上の戻り先へ
- 行き先が曖昧なボタンは、そのページのマイページ（利用者14／病院側14／管理者は02ダッシュボード）へ
- 全画面は index.html の一覧からも直接開ける（遷移が途切れても迷子にならない）
